# PIG_Reflectance_Classifier
Application to help in classifying coloring materials according to their spectral-reflectance signatures.
## Installation
To use the app, download the release folder and lauch PIG_Reflectance_Classifier.exe. It takes time (1 min) but eventually the app appears. From there, you can create your very own classification of the coloring-material database, based on spectral criteria.
To modify the app or launch it with Python, you can clone this repository and find the Python code in the _src_ folder.
## Usage 
Create classes by changing the threshold values of the criteria.
the thresholds can be saved using the _Save criteria_ button
